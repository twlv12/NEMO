

About Config values:

"neuronReuse"
Higher values increase initial interconnectivity

"topologyMutationRate"

Affects mutations which changes structure

"mathSuppressionExponent"
Scales math weight with percentage of math neurons
(-1:More math, 0:Disabled, 1:Linearly Suppress, 2:Strong)

"weightSharpness"
Sharpness controls gaussian distribution

"rewireOneChance"
"regenOneChance"
Rewire reconnects one end to existing neuron
Regen reconnects one end to new neuron
Lower regen increases interconnectivity

"sameTypeChance"
High values will make math development slower

"globalNewGeneRate"
Multiplier all mutation types which add genes

"geneSplitChance"
Increases chain length
